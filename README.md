# UniTutor

지금 내 수준에 맞춰 대학 공개 강의를 짧은 수업으로 이어 주는 적응형 웹 튜터다. iOS(Safari), Android(Chrome), Windows(Edge/Chrome), macOS(Safari/Chrome)의 기본 브라우저를 지원하며, 한 화면에서 강의를 보고 답을 받기 전에 질문을 받고 막히면 앞 개념으로 돌아갔다가 카드 한 장으로 세션을 닫는다.

제품 경험은 [docs/PRODUCT.md](docs/PRODUCT.md), 화면이 지킬 동작은 [ARCHITECTURE.md](ARCHITECTURE.md), 만드는 순서는 [ROADMAP.md](ROADMAP.md), 문서 배치와 작업 방식은 [AGENTS.md](AGENTS.md)에 있다. 구현과 실행 방법은 코드가 들어오면 각 컴포넌트 문서에 적는다.
